# Anima Odontologia

Corporate website developed for Anima Odontologia, a dental clinic located in Campeche, Florianópolis, SC.

🌐 Site: https://dradanielaconte.com.br/

## About the Project

The project arose from the need to establish a dedicated digital presence for the clinic, enabling it to
showcase its services, provide institutional information, and offer contact options to patients.

The application was developed from scratch based on the client's requirements, encompassing requirement gathering, interface design, feature implementation, and deployment to production.

## My Role

I was responsible for the end-to-end development of the project, including:

- Gathering and understanding the client's requirements;
- Defining the application structure;
- Developing the interface;
- Implementing features;
- Making adjustments during development based on feedback;
- Configuring the deployment;
- Deploying the application to production;
- Configuring the clinic's domain.

## Technologies used
- Next.js
- TypeScript
- Tailwind CSS
- Tabler Icons
- Netlify
- Registro.br

## Key features
- Responsive interface for desktop and mobile devices;
- Presentation of the clinic's services;
- Institutional information;
- Contact section;
- Optimized navigation;
- Deployment to a production environment;
- Clinic's own domain.

## Development Process
The project was developed without a pre-existing layout. Based on the client's needs, I defined the page structure, developed the interfaces, and made adjustments throughout the process as requirements were refined.

This approach made it possible to transform a business need into a deployed application used by the clinic.

## Results
The application was deployed to production and now serves as the clinic's corporate website.
